## LongTracker: A manual 3D cell tracking application. 

### Installing Longtracker:

1. _Install **MATLAB 2024b** (or more recent version) including **Image** and **Signal Processing** Toolboxes._
2. _Install **Java** on your computer (if not already installed)._
3. _Download the **Bio-formats: MATLAB toolbox** (bfmatlab.zip) located here: **https://www.openmicroscopy.org/bio-formats/downloads/**._
4. _Unzip bfmatlab.zip to a preferred directory.
5. _Add the directory (and sub-directory) containing the unzipped Bio-formats toolbox to the MATLAB paths: **MATLAB > Home tab > Set Path > Add with Subfolders.**_
6. _Download all **longtracker files** from **Github**, and add the preferred directory containing them to the MATLAB paths as well._
7. _In the MATLAB command window, type **longtracker** then press ENTER._
